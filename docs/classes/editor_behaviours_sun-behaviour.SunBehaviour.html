    Class SunBehaviour

    Controls the sun's position, color, and the day/night cycle in the scene. This behaviour simulates the sun's movement across the sky based on a time-of-day system, allowing for dynamic lighting changes. It also manages an optional moon simulation for night scenes. This component should be attached to an entity that represents the sun, typically a DirectionalLight.
