# Technical Blueprint: Editor Script Loading & Architecture

This document outlines how the Angular frontend interfaces with the Node.js compilation API, leverages browser Import Maps to resolve module dependencies, and dynamically handles lifecycle states without requiring page refreshes.

---

## 1. The Dynamic Import Map Configuration

Before the browser can evaluate any user code containing imports from `omega-game-engine`, an import map must be registered. This acts as a client-side module router.

### Configuration in `src/index.html`

Add this script tag inside the `<head>` of your Angular application. During development, ensure the path points to your statically served engine build.

```html
<script type="importmap">
  {
    "imports": {
      "omega-game-engine": "/assets/engine/index.js"
    }
  }
</script>

Angular Core Script Engine Service This service manages the lifecycle of the engine instance, issues compilation requests to the backend API, and executes the dynamic ES module imports using cache-busting identifiers. script-loader.service.ts TypeScript import { Injectable, inject } from '@angular/core'; import { HttpClient } from '@angular/common/http'; import { firstValueFrom } from 'rxjs'; @Injectable({ providedIn: 'root' }) export class ScriptLoaderService { private http = inject(HttpClient); private currentScriptUrl: string | null = null; private apiBaseUrl = 'http://localhost:3000/api'; // Replace with your Node API URL /** * Tells the backend to compile the project files into a single bundle, * then loads that bundle into the running browser context. * * @param projectUuid Unique identifier for the active project workspace * @returns The exported module containing user classes */ async loadProjectBundle(projectUuid: string): Promise<any> { // 1. Request the backend worker to execute the esbuild compilation loop // (The backend writes files to disk, runs esbuild, and updates the static bundle) await firstValueFrom( this.http.post(`${this.apiBaseUrl}/projects/${projectUuid}/compile`, {}) ); // 2. Clean up old references to allow memory to be garbage-collected this.unloadCurrentBundle(); // 3. Generate a cache-busting path using a precise high-resolution timestamp const timestamp = Date.now(); const bundleUrl = `${this.apiBaseUrl}/static/projects/${projectUuid}/dist/bundle.js?v=${timestamp}`; this.currentScriptUrl = bundleUrl; // 4. Dynamically import the script. // The browser intercepts 'omega-game-engine' and links it via the Import Map. const userModule = await import(/* @vite-ignore */ bundleUrl); return userModule; } /** * Revokes internal URL states if necessary or flags references for GC scrubbing. */ unloadCurrentBundle(): void { if (this.currentScriptUrl) { this.currentScriptUrl = null; } } } 3. WebGL Engine Instantiation & Reflection Loop This component illustrates how the editor completely tears down an active runtime context before instantiating a new bundle iteration, mapping user classes onto entities. editor-viewport.component.ts TypeScript import { Component, inject, OnDestroy, OnInit } from '@angular/core'; import { ScriptLoaderService } from './script-loader.service'; // Typing definition for your engine package context import { OmegaEngine } from 'omega-game-engine'; @Component({ selector: 'app-editor-viewport', template: `<canvas id="webgl-canvas"></canvas>`, standalone: true }) export class EditorViewportComponent implements OnInit, OnDestroy { private scriptLoader = inject(ScriptLoaderService); private engineInstance: OmegaEngine | null = null; private activeProjectUuid = 'your-project-uuid-here'; ngOnInit() { this.initEngineAndLoadScripts(); } /** * Orchestrates full destruction, compilation, and reloading sequence */ async initEngineAndLoadScripts() { // 1. Wipe previous engine instance out of memory entirely this.destroyCurrentEngine(); // 2. Initialize a pristine WebGL Context instance const canvas = document.getElementById('webgl-canvas') as HTMLCanvasElement; this.engineInstance = new OmegaEngine(canvas); try { // 3. Trigger API build compilation and resolve the ES Module const userBundle = await this.scriptLoader.loadProjectBundle(this.activeProjectUuid); // 4. Reflection Loop: Read custom exports appended to the ScriptRegistry if (userBundle && userBundle.ScriptRegistry) { Object.keys(userBundle.ScriptRegistry).forEach((className) => { const CustomBehaviorClass = userBundle.ScriptRegistry[className]; // Inspect class prototype methods const prototypeMethods = Object.getOwnPropertyNames(CustomBehaviorClass.prototype); console.log(`Loaded behavior: ${className}`, { hasStart: prototypeMethods.includes('start'), hasUpdate: prototypeMethods.includes('update') }); // Bind behavior classes to engine entities as needed // this.engineInstance.registerBehavior(className, CustomBehaviorClass); }); } // 5. Fire up the freshly compiled engine execution thread loop this.engineInstance.startLoop(); } catch (error) { console.error("Failed to compile or ingest script infrastructure bundle:", error); } } destroyCurrentEngine() { if (this.engineInstance) { this.engineInstance.stopLoop(); this.engineInstance.destroy(); // Ensure engine implementation drops WebGL refs & event listeners this.engineInstance = null; } } ngOnDestroy() { this.destroyCurrentEngine(); this.scriptLoader.unloadCurrentBundle(); } }</any>
